# Acceptance criteria reviewed 2026-10-17

## People-first content

https://developers.google.com/search/docs/fundamentals/creating-helpful-content

Original useful date tools, concise source-backed summaries; visible publisher/process; no fake expertise or ranking claim.

## Images

https://developers.google.com/search/docs/appearance/google-images

Real adjacent captions, descriptive alt and names, srcset/sizes, explicit dimensions, original aspect ratio.

## Article

https://developers.google.com/search/docs/appearance/structured-data/article

One accurate Article; visible headline/content/process; truthful modification date and Organization author.

## Breadcrumb

https://developers.google.com/search/docs/appearance/structured-data/breadcrumb

Three-level path with real crawlable URLs.

## Event

https://developers.google.com/search/docs/appearance/structured-data/event

Calendar observances are not fabricated ticketed events; no Event markup.

## Essentials

https://developers.google.com/search/docs/essentials

Indexable HTML, unique metadata, sitemap, real links; eligibility is not a ranking guarantee.

## Commons reuse

https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia

Per-file copyright, author and non-copyright restrictions reviewed; no assumption all Commons media has same license.

## Commons licenses

https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/licenses

Credit, original link, license deed, changes; ShareAlike preserved on derivatives.

## Wikimedia attribution

https://attribution.wikimedia.org/attribution-signals/license.html

Actual imageinfo metadata and original file revisions; visible nearby creator and license links.

All guide copy is Lithuanian and AI reviewed. No independent native-human or legal certification is claimed.
